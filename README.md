# 🐍 Python Learning Site

A simple educational website built with **Flask** and **SQLite** — created by a self-taught developer learning backend from scratch.

## ✨ Features
- ✅ Full **CRUD** system (Create, Read, Update, Delete)
- ✅ SQLite database integration
- ✅ Clean interface with **Bootstrap 5**
- ✅ Pages explaining core concepts:
  - Logic & flow control
  - Variables
  - Functions
  - Object-Oriented Programming (OOP)
  - Databases
  - Frameworks

## 🛠️ Built With
- Python 3
- Flask — lightweight web framework
- SQLite — built-in database
- HTML5 + Bootstrap 5

## 🚀 How to Run Locally
```bash
# Install dependencies
pip install -r requirements.txt

# Run the app
python app.py
